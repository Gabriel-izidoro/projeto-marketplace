# Shopping Virtual

Projeto de um sistema completo que conecta pessoas a lojas regionais de diversos departamentos com entrega embutida.

## Sobre o projeto

O projeto nasceu para resolver a dificuldade de pequenos lojistas em vender online sem depender de grandes plataformas, ao mesmo tempo em que oferece aos compradores um único lugar para encontrar produtos de diversos vendedores locais, com entrega integrada. O diferencial é a vídeo chamada feita diretamente entre lojista e comprador, trazendo acessibilidade tecnológica e mais facilidade na comunicação entre as partes.

O sistema conta com três tipos de usuário: **Comprador**, que navega e compra produtos; **Lojista**, que cadastra produtos e gerencia pedidos; e **Entregador**, responsável por realizar as entregas.
