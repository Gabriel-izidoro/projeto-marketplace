# Requisitos Funcionais

## Cadastro -- Comprador 

### RF-CAC-01 - Cadastro do comprador
**Descrição:** O comprador deve conseguir se cadastrar com email, nome, endereço e senha  
**Prioridade:** Alta
**Plataforma:** Site, App
**Status:** Pendente

### RF-CAC-02 - Cadastro alternativo
**Descrição:** O comprador deve conseguir se cadastrar via Google/Facebook  
**Prioridade:** Média
**Plataforma:** Site, App
**Status:** Pendente

### RF-CAC-03 - Recuperar Senha
**Descrição:** O comprador deve conseguir recuperar a senha por email  
**Prioridade:** Alta
**Plataforma:** Site, App
**Status:** Pendente

## Cadastro -- Lojista

### RF-CAL-01 - Cadastro do lojista
**Descrição:** O lojista deve se cadastrar com CNPJ, email e senha  
**Prioridade:** Alta
**Plataforma:** Site, App
**Status:** Pendente

### RF-CAL-02 - Confirmação de CNPJ
**Descrição:** O sistema deve validar o CNPJ antes de aprovar o cadastro do lojista  
**Prioridade:** Alta
**Plataforma:** Site, App
**Status:** Pendente

### RF-CAL-03 - Usuário admin e equipe
**Descrição:** O lojista deve poder adicionar um usuário admin e outros usuários da equipe  
**Prioridade:** Média
**Plataforma:** Site, App
**Status:** Pendente

### RF-CAL-04 - Recuperação de senha (lojista)
**Descrição:** O lojista deve conseguir recuperar a senha por email  
**Prioridade:** Média
**Plataforma:** Site, App
**Status:** Pendente

## Cadastro -- Entregador

### RF-CAE-01 - Cadastro do entregador
**Descrição:** O entregador deve se cadastrar com o numero da CNH, CRV do veiculo, email e senha  
**Prioridade:** Alta
**Plataforma:** Site, App
**Status:** Pendente

### RF-CAE-02 - Validar CNH
**Descrição:** O sistema deve validar a CNH antes de aprovar o cadastro do Entregador  
**Prioridade:** Alta
**Plataforma:** Site, App
**Status:** Pendente

### RF-CAE-03 - Validar CRV
**Descrição:** Os sistema deve validar a CRV antes de aprovar o cadastro do entregador  
**Prioridade:** Alta
**Plataforma:** Site, App
**Status:** Pendente

### RF-CAE-04 - Recuperação de senha (entregador)
**Descrição:** O entregador deve conseguir recuperar a senha por email  
**Prioridade:** Alta
**Plataforma:** Site, App
**Status:** Pendente

## Autenticação de conta

### RF-AUT-01 - Login
**Descrição:** O sistema deve permitir que o usuário acesse sua conta utilizando email e senha  
**Prioridade:** Alta
**Atores:** Comprador, Lojista, Entregador
**Plataforma:** Site, App
**Status:** Pendente

## Navegação

### RF-NAV-01 - Hub básico
**Descrição:** O sistema deve permitir que o usuário acesse as seções home, histórico, configurações e perfil a partir de um menu de navegação  
**Prioridade:** Alta
**Atores:** Comprador
**Plataforma:** Site, App
**Status:** Pendente

### RF-NAV-02 - Pesquisa
**Descrição:** No home o usuario deve conseguir pesquisar por palavras chave sobre o produto que ele deseja  
**Prioridade:** Alta
**Atores:** Comprador
**Plataforma:** Site, App
**Status:** Pendente

### RF-NAV-03 - Fila do lojista
**Descrição:** O sistema deve permitir que o lojista visualize a fila de cliente em espera  
**Prioridade:** Média
**Atores:** Lojista
**Plataforma:** Site, App
**Status:** Pendente

### RF-NAV-04 - Denuncia
**Descrição:** O sistema deve permitir denuncia a usuarios de qualquer ator  
**Prioridade:** Alta
**Atores:** Comprador, Lojista, Entregador
**Plataforma:** Site, App
**Status:** Pendente

### RF-NAV-05 - Confirmação de chamada
**Descrição:** O usuario deve confirmar antes de entrar em qualquer chamada  
**Prioridade:** Alta
**Atores:** Comprador, Lojista
**Plataforma:** Site, App
**Status:** Pendente

## Acessibilidade

### RF-ACE-01 - Ajuste de tamanho de fonte
**Descrição:** O sistema deve permitir que o usuário aumente ou diminua o tamanho da fonte do texto da interface  
**Prioridade:** Média
**Atores:** Comprador, Lojista, Entregador
**Plataforma:** Site, App
**Status:** Pendente
